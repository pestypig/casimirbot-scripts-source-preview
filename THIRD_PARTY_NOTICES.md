Their URLs and identifiers are source references; the underlying documents, weights, geographic data, and downloaded outputs are not licensed or redistributed by this draft. Review each source's own terms before acquiring or publishing outputs.

Two scripts refer directly to external source repositories. `scripts/hull-mis-clone.ts` names [RayTracingMIS](https://github.com/ComputationallyBased/RayTracingMIS) and can clone its `main` branch or update an existing local checkout when run. Both upstream repositories displayed MIT licenses at the October 18, 2026 review ([RayTracingMIS license](https://github.com/ComputationallyBased/RayTracingMIS/blob/main/LICENSE), [GeneralRelativisticMaxwell license](https://github.com/lanyonai/GeneralRelativisticMaxwell/blob/main/LICENSE)). Neither upstream source tree or license file is bundled here. Obtain and review each external project separately before running these scripts or redistributing its outputs.

Many scripts can write local files, launch processes, contact an endpoint, or probe a live provider when run with the right environment. Some refer to deployment or developer-only services. Publication of their text would not authorize an agent to execute them, imply that a service is available, or grant account, data, game, or environment permissions.
